# CounterNote Beta Support

Use [GitHub Issues](https://github.com/counternote-ai/counternote/issues) for beta bugs, questions, and feature requests.

For a bug, include:

- CounterNote version
- macOS version and Mac model/chip
- What you expected and what happened
- Reproduction steps
- Whether Screen Recording and Microphone permissions were granted
- Screenshots or sanitized logs when useful

Do not attach recordings, transcripts, API keys, personal data, or sensitive workplace information to a public issue.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
